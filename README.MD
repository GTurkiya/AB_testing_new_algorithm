# A/B-тестирование нового алгоритма рекомендаций постов для ленты новостей

### Описание проекта
Одним из продуктов компании является приложение для ленты новостей. Коллеги из отдела машинного обучения разработали новый алгоритм рекомендации постов. Ожидается, что после внедрения этого алгоритма пользователи будут ставить лайки чаще. Цель проекта - провести A/B-тест, чтобы оценить примерный эффект от внедрения нового алгоритма и понять, действительно ли он лучше, чем старый.

### Стек
Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn, SQL, статистические критерии

### Выполненные задачи
1. Выгрузил данные из базы с помощью SQL-запросов
2. Выбрал метрику (CTR из просмотров в лайки), изучил распределения и сформулировал гипотезы
3. Провёл A/A‑тест (по 10000 пользователей в группе) — подтвердил эквивалентность групп ($p‑value > 0,05$)
4. Провел A/B-тест (1 неделя, по 10000 пользователей в группе) и оценил эффект с помощью статистических тестов (t-тест, тест Манна-Уитни, Пуассоновский бутстреп, бакетное преобразование)
5. Проанализировал результаты и сформулировал рекомендации

### Основные результаты
1. Обнаружено, что CTR в тестовой группе имеет бимодальное распределение, при этом его среднее значение не отличается от среднего значения в контрольной группе.
2. Были обнаружены статистически значимые изменения ($p-value < 0,05$, количество лайков уменьшилось), связанные с внедрением нового алгоритма.
3. Было рекомендовано не раскатывать алгоритм на всех пользователей приложения, что позволило избежать снижения пользовательской активности.
